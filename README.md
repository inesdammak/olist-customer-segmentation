
# Olist Customer Segmentation & Predictive Marketing

## Business Context

Olist is an e-commerce marketplace platform that wants to improve its CRM and marketing performance through customer segmentation and predictive scoring.

The objective is to identify customer profiles, prioritize marketing actions and improve retention.

---

## Project Objectives

- Segment customers using RFM analysis
- Build a customer scoring model
- Create actionable marketing personas
- Measure segment stability over time
- Recommend a CRM activation strategy

---

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-Learn
- K-Means Clustering
- RFM Analysis
- Matplotlib
- Seaborn

---

## Methodology

1. Data Cleaning
2. Exploratory Data Analysis
3. Feature Engineering
4. RFM Scoring
5. Customer Segmentation (K-Means)
6. Customer Scoring
7. Marketing Personas
8. Segment Stability Analysis

---

## Key Results

- Customer segmentation into 4 profiles
- Customer value score (0–100)
- Marketing activation strategy
- Maintenance and retraining recommendations
